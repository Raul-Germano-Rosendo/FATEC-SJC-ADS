# Equação Linear
    Toda equação da forma a¹ x¹ + a² x² + ... + a´n x´n = b é denominada __Equação Linear__ em que:

    a¹,a²,...,a´n são coeficientes
    x¹,x²,...,x´n são as incógnitas
    b é um termo independente
